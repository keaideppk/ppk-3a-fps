## 核心特性

一整个射击战役塞进单个 HTML 文件：四章自由选关、七槽位军械库（四把 CAD 手工建模枪械 + 两款投掷物）、四类 GPU 蒙皮多骨骼硬表面敌军、两台多阶段 Boss、实时旋转战术雷达，以及可无级微调的难度系统。

| | 特性 | 说明 |
| :--- | :--- | :--- |
| 🎯 | **四章战役** | 自由选关，每章独立地形、环境危害与 Boss。 |
| 🔫 | **七槽位军械库** | 四把精工枪械 + 破片/EMP 手雷，战中随时切换。 |
| 🤖 | **蒙皮敌军** | 多骨骼硬表面模型，支持部位命中判定。 |
| 👹 | **多阶段 Boss** | 部位可破坏、护盾击碎、核心强制暴露、狂暴阶段。 |
| 🗺️ | **实时战术雷达** | 旋转小地图，区分兵种并带屏外贴边指引。 |
| 🎚️ | **自由难度调节** | 五档预设 + 五项无级滑块 + 不死护体。 |
| 🕹️ | **多端输入** | 键鼠、手柄、触屏，同一份构建全支持。 |
| 📦 | **零依赖** | 单个 `index.html`，无 CDN、无构建步骤、运行期零网络请求。 |

## 战役

每章都是一次独立行动：切断上行链路、撕开防线、顶住反扑、登艇撤离。

| # | 章节 | 场景 | 任务 | Boss |
| :-: | :--- | :--- | :--- | :--- |
| 01 | **四号泊位封锁线** | 自动化集装箱港区 · 雨夜 | 切断 3 处上行中继后登艇撤离 | — |
| 02 | **远洋巨轮与中枢决战** | 深水联体中枢甲板 | 瘫痪 2 座护盾发生器 | **ppk巨像** |
| 03 | **船坞总装厂** | 分段船体总装线 | 切断中控塔、熔铸车间与坞门泵站三段供电 | **泰坦总装体** |
| 04 | **深渊地热环站** | 熔核环厅 | 切断 3 处地热供给锁 | **ppk渊龙** |

**环境危害** —— 第三章新增天车吊运、等离子切割臂贴地扫掠与蒸汽爆管；第四章新增旋转环廊与地热熔流。

## 军械库

全部枪械均由代码程序化建模：倒角机匣、精铣导轨齿、镂空全息瞄具与消视差镜片、液压杆与编织软管，无任何外部模型资源。

| 槽位 | 武器 | 说明 |
| :-: | :--- | :--- |
| `1` | **ppk九式突击步枪** | 基础全自动步枪，含待机审视动画 |
| `2` | **ppk破浪十二式霰弹枪** | 8 弹丸齐射，支持换弹中途打断 |
| `3` | **ppk惊雷式电磁轨道狙击枪** | 蓄力穿透射击，开镜 80% 切入高倍镜 |
| `4` | **ppk蜂群式冲锋手枪** | 1020 发/分，28 发加长弹匣 |
| `5` | **ppk九七式破片高爆手雷** | 左键高抛 / 右键贴地低抛 |
| `6` | **ppk惊蛰式 EMP 脉冲手雷** | 破盾、瘫痪并强制暴露 Boss 核心 |

## 技术说明

| | |
| :--- | :--- |
| **渲染** | 内置 Three.js 的 WebGL 2 渲染，自研后期管线：时域上采样、SSAO、体积光、辉光、动态模糊、电影级色调映射。 |
| **材质** | 启动时程序化生成 PBR 贴图：拉丝钢、阳极氧化铝、聚合物、锈蚀、附生物、湿润与雨水法线，零图片资源。 |
| **物理** | AABB 碰撞世界 + 胶囊扫掠 + 台阶处理 + A\* 导航网格，并为飞行单位实现连续三维子步进退穿解算，杜绝穿模。 |
| **音频** | 100% 程序化合成音频：所有枪声、伺服声、咆哮与撞击均在加载时由噪声、滤波器与包络实时生成。 |
| **体积** | 单文件不足 2 MB，运行期零网络访问。 |
