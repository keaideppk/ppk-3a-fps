# ppk · 3A大作

> **来源与二次开发声明**：本项目原版基底源自 **Claude 官方示例**；当前仓库版本在此基础上使用 **Carbon 模型** 进行了深度**二次开发（二开）**与玩法拓展（涵盖全新第二章远洋巨轮中枢关卡、四式精工 CAD 武器与手持双模战术手雷、三大新锐敌军兵种、多阶段巨型机甲 Boss、实时旋转战术雷达小地图、自由难度调节系统以及飞行敌军三维体积防穿模物理修复等）。

一款纯单文件、零外部依赖的硬核科幻港区第一人称战术射击网页游戏（支持桌面端键鼠、手柄与移动端触屏直连游玩）。

## 核心特性

- **双章节战役自由选关**
  - **第一章 · 四号泊位封锁线**：雨夜潜入自动化集装箱港区，突破立体防线，切断三处上行中继并登艇撤离。
  - **第二章 · 远洋巨轮与泰坦决战**：登临深水联体中枢甲板，瘫痪货舱与舰桥双护盾发生器，迎战多阶段巨型机甲 Boss **“ppk巨像”**。
- **精工军械库与手持双模战术手雷**
  - `1` **ppk九式突击步枪** · `2` **ppk破浪十二式霰弹枪** · `3` **ppk惊雷式电磁轨道狙击枪** · `4` **ppk蜂群式冲锋手枪**
  - `5` **ppk九七式破片高爆手雷** · `6` **ppk惊蛰式 EMP 脉冲手雷**（支持左键高抛远投 / 右键贴地低抛）
- **实时战术雷达小地图 & 自由难度调节**
  - 左上角实时旋转小地图（按 `M` 切换 `42m / 78m` 视野）。
  - 主菜单与战斗暂停界面（`Esc`）支持五档难度预设、五项参数无级滑块微调及“不死护体”模式，随时切换立即生效。

## 键鼠操作说明

| 操作 | 按键 |
| :--- | :--- |
| 移动 / 冲刺 / 跳跃 / 蹲伏 | `W` `A` `S` `D` / `Shift` / `Space` / `C` |
| 开火 / 开镜瞄准（或手雷高抛 / 低抛） | `鼠标左键` / `鼠标右键` |
| 切换武器与手雷 | 数字键 `1`–`6` 或 `鼠标滚轮` |
| 快捷切手雷上手 / 互换破片与 EMP 雷 | `G` / `Q`（或 `T`） |
| 手动换弹 / 枪托近战 / 场景交互 | `R` / `F` / `E` |
| 小地图缩放 / 暂停与难度调节 | `M` / `Esc` |

## 项目来源与二开说明

- **原作基底来源**：**Claude 官方示例**
- **二次开发模型**：**Carbon 模型**
- **二开主要拓展内容**：
  1. 双章节自由选关与第二章“远洋巨轮·深水联体中枢甲板”完整关卡构建及战术补给站；
  2. 新增精工霰弹枪、电磁轨道狙击枪、冲锋手枪及滚轮切换上手的破片 / EMP 双模战术手雷，完善开镜射击与手动/自动换弹体验；
  3. 新增高标准 GPU 蒙皮多骨骼敌军（自爆巡飞蜘蛛雷、鹰眼浮游炮、重装蜂巢能量盾卫）与多阶段压轴泰坦 Boss **“ppk巨像”**；
  4. 新增左上角实时旋转战术小地图、五档预设 + 无级微调 + 不死护体的自由难度调节系统；
  5. 重构飞行单位连续三维圆柱体积退穿与集装箱智能翻越/空域边界算法，解决空中敌军穿模问题。
- 本项目仅供学习、测试与技术交流使用。
